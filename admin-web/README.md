# 商管营销宝 - Web 管理端

基于 Vue 3 + Element Plus 的管理后台，对应《mp.md》任务拆解清单中 **管理员模块（第四章）** 及 **公共基础模块（第一章）**。

## 技术栈

- Vue 3（Composition API + `<script setup>`）
- Vite
- Vue Router
- Pinia（用户/项目全局状态）
- Element Plus
- ECharts（数据看板）
- Axios

## 页面清单

### 1. 公共基础
| 页面 | 路由 | 说明 |
|---|---|---|
| 登录页 | `/login` | 账号/密码、记住账号、忘记密码跳转 |
| 重置密码页 | `/reset-password` | 手机号/邮箱验证 + 新密码设置 |
| 项目选择弹窗 | 登录后强制弹出 | 展示有权限的项目列表，确定后进入工作台 |
| 项目切换 | 个人中心内 | 切换后刷新全局数据 |

### 2. 管理员功能
| 页面 | 路由 | 说明 |
|---|---|---|
| 工作台首页 | `/dashboard` | 统计卡片（客户总数/销售录入/渠道推荐/公共池/过期池/待审批高亮）+ 快捷入口 |
| 新增客户录入 | `/customer/create` | 到访渠道全部可选；渠道推荐选公司；个人推荐填推荐人；可指定归属销售员 |
| 全部客户管理 | `/customers` | 多维筛选（项目/来源/归属人/意向/状态/时间）+ 搜索 |
| 客户详情 | `/customers/:id` | 完整信息 + 水印照片、编辑、跟进记录、归属调整、流转日志 |
| 公共池管理 | `/public-pool` | 认领审批（同意/驳回）、手动分配 |
| 未到访申领审批 | `/unvisited-approvals` | 待办列表 + 审批同意/驳回 |
| 过期池管理 | `/expired-pool` | 仅查看（原始报备、是否重报），不可编辑 |
| 数据导出 | `/export` | 多条件筛选导出 Excel，记录导出日志 |
| 项目管理 | `/settings/projects` | 仅系统管理员可编辑 |
| 账号角色管理 | `/settings/users` | 新增/禁用/重置密码/分配项目，仅系统管理员可操作 |
| 合作公司管理 | `/settings/companies` | 仅系统管理员可编辑 |
| 系统参数配置 | `/settings/config` | 30天进公共池 / 24h过期 / 4h时间偏移 |
| 操作日志 | `/audit-logs` | 不可删除，按项目/人员/时间筛选 |
| 个人中心 | `/profile` | 项目切换、修改密码、退出登录 |

### 3. 数据看板
| 页面 | 路由 | 说明 |
|---|---|---|
| 客户漏斗看板 | `/boards/funnel` | 报备→到访→跟进→成交 各环节转化率，按项目/时间筛选 |
| 销售业绩看板 | `/boards/sales` | 销售员排名：客户数/到访数/成交数/跟进及时率，柱状图 + 排行榜 |
| 渠道贡献看板 | `/boards/channel` | 各合作公司推荐量/到访率/过期率趋势，渠道员推荐 Top 榜 |
| 跟进预警看板 | `/boards/warning` | 即将满 30 天未跟进客户分布（按销售员/意向等级聚合），红色预警高亮 |
| 实时动态看板 | `/boards/activity` | 今日新增/到访/跟进/审批 实时流转动态流，适合投屏 |

看板统一使用 ECharts 渲染，支持项目维度筛选，数据来源于统计类接口（`GET /api/admin/dashboard` 及扩展统计接口）。

## 权限约定

- **系统管理员**（`isSystemAdmin = true`）：全部权限，可见项目管理/账号管理/合作公司管理入口及新建、编辑、重置密码按钮
- **普通管理员**：仅可调阅、查阅，隐藏上述入口及按钮
- 项目管理、账号管理、合作公司管理对应的后端 POST/PUT 接口均受 `requireSystemAdmin` 保护

## 关键业务规则（前端配合）

- 管理员可查看全部手机号（不脱敏）
- 到访时间不能晚于系统时间 4 小时以上（前端校验 + 后端强制）
- 提交前防抖调用手机号查重接口，冲突时走审批流程
- 图片上传自动加水印（项目名 + 时间）
- 所有修改/分配/审批/导出操作由后端记录审计日志

## 目录结构（规划）

```
admin-web/
├── src/
│   ├── api/          # 接口封装（按模块拆分）
│   ├── assets/       # 静态资源
│   ├── components/   # 公共组件（项目选择弹窗、统计卡片等）
│   ├── layouts/      # 布局（侧边栏 + 顶栏 + 内容区）
│   ├── router/       # 路由 + 权限守卫
│   ├── stores/       # Pinia（user / project）
│   ├── utils/        # 工具（request 封装、脱敏、校验）
│   └── views/        # 页面（按上述清单分目录）
├── .env.example
└── vite.config.js
```
